# Fonts

The Markus design system's faces, subset to Latin as WOFF2, all under the SIL Open Font License 1.1:

- Geist (400, 500, 600) for reading.
- Geist Mono (400, 500) for code and labels, and Geist Mono 600 for headlines.

Geist and Geist Mono are by Vercel. The 600 weight of Geist Mono comes from Fontsource (`@fontsource/geist-mono` 5.2.5).
